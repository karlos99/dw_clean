How to Build Custom Dashboards

  • 1

    Visual Dataset Builder

    Select a base table (e.g. Student lists or Test configurations), visually join other related tables, add filters, and choose columns.

  • 2

    Configure Saved Charts

    Select your newly built dataset (or existing exploration query). Map fields to X/Y axes, apply aggregations (Count, Sum, Avg), and style using Apache ECharts.

  • 3

    Drag & Drop Dashboard Layouts

    Drag your configured charts onto a grid layout. Add rich text notes. Toggle publishing to automatically link the page in the main navigation menu!

Data Security

All dynamically compiled datasets respect the application's row-level security. User role scopes and assigned schools are automatically injected as strict SQL query filters.
